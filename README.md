# mumak-back

Mumak의 백엔드 저장소입니다.

브라우저 기반 음악 스케치·작곡·간단 녹음 서비스의 서버 기능을 위한 저장소입니다.

## 향후 구현 범위

- 프로젝트 저장 및 조회 API
- 녹음 파일 및 오디오 자산 관리
- 사용자 인증 및 프로젝트 접근 제어

실시간 악기 재생과 오디오 처리는 우선 브라우저에서 수행합니다. 서버 기능은 프론트엔드 시제품의 요구에 맞춰 단계적으로 구현합니다.

현재는 저장소 초기화 단계이며, 서버 코드와 기술 스택은 아직 확정되지 않았습니다.

## 관련 저장소

- 프론트엔드: https://github.com/solchaan/mumak-front
